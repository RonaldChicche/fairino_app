Principios
RLS activado en todas las tablas y ninguna política abierta al público.
El navegador nunca habla con Supabase: todo pasa por la web.
La clave de servicio vive solo en las variables de entorno de Vercel, nunca en el repositorio.
El token de R2 vive en el .env del edge, que Git ignora, y se limita al bucket.
Pospuesto durante las pruebas (D34): protección de la red local del edge y capa de seguridad de Cloudflare para las URLs compartidas. El panel del operador no tiene login, así
que cualquier dispositivo en el wifi del edge podría pulsar Go: es un riesgo aceptado mientras se prueba y hay que revisarlo antes de operar con público.
