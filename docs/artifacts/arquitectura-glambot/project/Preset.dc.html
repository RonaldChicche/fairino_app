La app lo fija desde la API de la cámara

Resolución y fps: 4K a 120 fps (D19).

Lente: Wide (D19), con margen para recortar a 9:16.

HyperSmooth: apagado (D7). El brazo ya se mueve suave y la estabilización recorta y deforma sin vuelta atrás.

Bitrate: alto (D7).

Anti-parpadeo: 60 Hz, la red eléctrica de Perú. A 120 fps las luces LED parpadean si esto está mal.

Nivelación de horizonte: apagada, porque recorta la imagen.

Modo de rendimiento: máximo rendimiento.

Apagado automático: nunca.
Se fija una vez en la cámara, sin API
La API pública de la HERO10 no los expone. Se guardan en un preset de la cámara.

Nitidez: baja (D7).

Balance de blancos: fijo (D7), ajustado a la luz del evento.

ISO máximo: acotado (D7). Con buena luz no hace falta subirlo.

Shutter: rápido, para que el movimiento no salga borroso. Falta medir cuál.

Perfil de color: Flat o Natural. Pendiente en Notion, bloque D.
Preset de cámara: máxima calidad en movimiento
