# contracts

Esquemas compartidos por `apps/edge` y `apps/web`: sesión, catálogo de rutas, plantilla de evento y estados. Se definen una sola vez aquí.

No le corresponde: lógica de negocio, acceso a datos ni código propio de una sola app. Definiciones pendientes en Notion: C1 (sesión), C4 (rutas), C5 (plantilla).
